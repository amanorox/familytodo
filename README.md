# まいにちのTODOリスト（家族用）

小学生のお子さん向けの、毎日のやることリストです。HTML + JavaScriptのみで動作し、サーバー保存は不要です。

## ファイル構成

- `index.html` … 画面本体
- `style.css` … デザイン
- `app.js` … 動作ロジック
- `edit.html` / `edit.js` … TODOリストの編集ページ（画面上から追加・変更・削除ができます）
- `todo-diff.js` … `todo.txt` の内容と、編集ページで保存した差分を合成する共通ロジック
- `todo.txt` … **やることリストの中身**（ここを編集すればリストを自由に変更できます）

## todo.txt の書き方

1行に1つ、やることを書くだけです。空行や `#` で始まる行は無視されます。

```
はやおきする
はをみがく
きがえる
あさごはんをたべる
しゅくだいをする
```

### 曜日を指定する

行の先頭に曜日キーワード（`SUN` `MON` `TUE` `WED` `THU` `FRI` `SAT`）を書くと、
その曜日だけリストに表示されます。カンマ区切りで複数曜日も指定できます。
曜日を書かない行は、これまで通り**毎日**表示されます。

```
はやおきする
MON,WED,FRI ピアノのれんしゅうをする
SAT,SUN おへやのおかたづけをする
```

## 画面から編集する（todo.txtを直接さわれない場合）

トップ画面左上の「✏️ 編集」リンクから、`todo.txt` を直接編集しなくてもブラウザ上でやることの追加・変更・削除ができます。

- ここでの変更は `todo.txt` そのものを書き換えるのではなく、**この端末のブラウザに「差分」として保存**されます（`todo.txt` の内容 + 差分 を合成して表示します）。
- そのため、他の端末やブラウザには反映されません。全員に反映したい・恒久的に残したい内容は、管理者が `todo.txt` を直接編集してください。
- 「↩ 元の内容にもどす」を押すと、保存した差分がすべて消え、`todo.txt` そのままの内容に戻ります。
- 各行の「毎日」チェックを外すと、表示する曜日を個別に選べます（`todo.txt` の曜日キーワードと同じ仕組みです）。

## 使い方

`index.html` は `fetch()` で `todo.txt` を読み込むため、**ブラウザで直接ファイルを開く（file://）と読み込みに失敗します**。
必ず簡易的なWebサーバー経由で開いてください。

### 方法1: Pythonがある場合

```powershell
cd familytodo
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。

### 方法2: Node.jsがある場合

```powershell
npx serve .
```

表示されたURL（例: `http://localhost:3000`）を開きます。

### 方法3: VSCodeの「Live Server」拡張機能

`index.html` を右クリック →「Open with Live Server」

## スマホ（Android）にアプリとしてインストールする

AndroidのChromeで「アプリとしてインストール」（ホーム画面にアイコンを追加して、ブラウザのアドレスバーなどが出ない状態で起動できる）ようにするには、**HTTPS（安全な接続）で配信されているサイト**を開く必要があります。

`python -m http.server` などでパソコン上にサーバーを立てて、スマホから `http://192.168.x.x:8000` のような**社内LANのIPアドレス＋http**でアクセスした場合、ブラウザは「安全な接続ではない」と判断し、メニューに「アプリをインストール」ではなく「ブックマークに追加」しか出てきません（`http://localhost` はパソコン自身から見る場合のみ例外的にOKですが、スマホからは別扱いになります）。

インストール可能なPWAとして使うには、以下のいずれかの方法でHTTPS経由で公開してください。

### 方法A: GitHub Pages で公開する（無料・おすすめ）

1. このフォルダの内容をGitHubリポジトリにpushする
2. リポジトリの Settings → Pages で公開する
3. 発行された `https://ユーザー名.github.io/リポジトリ名/` をスマホのChromeで開く
4. メニューから「アプリをインストール」を選ぶ

### 方法B: 一時的にHTTPSトンネルを使う（お試し用）

```powershell
npx localtunnel --port 8000
```

または [ngrok](https://ngrok.com/) などを使うと、一時的なHTTPS URLが発行されます。そのURLをスマホで開いてインストールしてください。

### インストールできているか確認するポイント

- Chromeのメニューに「アプリをインストール」（「ホーム画面に追加」ではなく）と表示されるか確認する
- 一度インストールした後にアイコンやマニフェストを変更した場合は、スマホ側で一度アプリをアンインストールしてから開き直す（キャッシュが残るため）

## 使い方（お子さん・親御さん向け）

- 表の「こどもチェック」列は、やることをやったらお子さんがチェックします。
- 「おやチェック」列は、親御さんが確認したらチェックします。
- チェック状態はブラウザに保存され、**日付が変わると自動的に未チェックへリセット**されます（todo.txtの内容自体は変わりません）。
- リストの内容を変えたいときは `todo.txt` を編集し、画面の「🔄 リストをよみこみなおす」ボタンを押してください。

## 注意

- チェック状態はブラウザ（端末）ごとのlocalStorageに保存されるため、別の端末やブラウザとは共有されません。
- 家族内利用を想定しているため、パスワードなどの認証機能はありません。
